# v1.4.0 — 2026-11-04

Minor release. Previous: [v1.3.0](v1.3.0.md) · Diff: `git log v1.3.0..v1.4.0`

## Features

- `middlewares.CachedAuth(authenticate, ttl)` wraps an `AuthServiceFunc` so that a token
  it accepted is trusted for `ttl` without calling auth again. Without it, every
  authenticated request costs a round-trip to auth's `/auth/me`. Tokens are keyed by
  their SHA-256. Refusals and errors are never cached. Expired entries are removed when
  a new token is stored.

## Upgrade notes

- No API changes. To use the cache, wrap the function you already pass to
  `AuthMiddleware` and the gRPC interceptors:
  `mw.CachedAuth(mw.NewAuthMeFunc(authURL, nil), time.Minute)`. Build it once and share
  it, so REST and gRPC use the same cache.
- Keep `ttl` short. A token that auth revokes is still accepted until its entry expires.
