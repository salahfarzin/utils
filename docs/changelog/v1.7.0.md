# v1.7.0 — 2026-11-15

Minor release. Previous: [v1.6.0](v1.6.0.md) · Diff: `git log v1.6.0..v1.7.0`

## Features

- `tags`: the tagging every service shares, as `docs/tags.md` (the contract) has it. A tag
  is general (managed with auth's `tags` resource, `edit`) or one user's own; names are
  normalized (`Normalize`) and unique per owner ignoring case. `Store` keeps one kind of
  record's tags in Postgres (a tags table and a links table): the catalog with counts
  (`Catalog`), `Create`/`Rename`/`Delete` (a general tag takes over users' own tags of its
  name), setting a record's tags by name (`Resolve`, `Set`), a list filter on any or all
  of them (`Lookup`, `Filter`), a list's search matching tag names (`Named`) and a page of
  records' tags (`Of`). s3's files are the first to use it.

## Changes

- `go.mod` now says `go 1.27.4` (was 1.27.3). A service that bumps to v1.7.0 gets its own
  `go` line raised to at least 1.27.4 by `go mod tidy`, so its Docker build image needs
  that toolchain.
