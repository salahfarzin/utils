# v1.3.0 — 2026-10-24

Minor release. Previous: [v1.2.0](v1.2.0.md) · Diff: `git log v1.2.0..v1.3.0`

## Features

- `Truncate(s, n)` cuts a string to at most `n` bytes without splitting a multibyte rune, so
  valid UTF-8 stays valid. Use it for byte limits such as a column's length. If the cut
  falls inside a rune, the whole rune is dropped, so the result can be shorter than `n`.
  A limit of `0` or less returns `""`.

## Fixes

- `db.NewMySQLStorage` now sets the session time zone to UTC (`time_zone = '+00:00'`) on
  every connection in the pool. Before, it ran `SET time_zone` once after connecting, which
  only reached one pooled connection and ignored errors. Other connections used the
  server's time zone, so `NOW()`, `CURRENT_TIMESTAMP` and `TIMESTAMP` columns could
  disagree with the UTC `time.Time` values the driver reads and writes (`Loc: time.UTC`).
  The setting is now passed in the DSN, so the driver applies it to each new connection.

## Upgrade notes

- No API changes. If your code worked around the time zone mismatch (for example by running
  `SET time_zone` itself or converting `TIMESTAMP` values by hand), you can remove that.
- Check any stored data that was written through a non-UTC session. `TIMESTAMP` values are
  stored in UTC and converted on read, so they were fine. Values written with `NOW()` into
  `DATETIME` columns used the server's time zone, and from this release they are written in
  UTC.
