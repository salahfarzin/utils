# v1.8.0 — 2026-11-16

Minor release. Previous: [v1.7.0](v1.7.0.md) · Diff: `git log v1.7.0..v1.8.0`

## Features

- `audit`: who did what to which record, as `docs/audit.md` has it. `Recorder` publishes
  schema-v1 events to Kafka (`audit-events`) for the audit service. `Before`/`After` take
  any JSON-encodable state; the field-level diff walks nested objects, matches array
  elements by `id`/`uuid` (an insert doesn't mark every element changed) and writes JSON
  Pointer paths (`/variants/id=v1/stock`). Secrets are redacted by whole-word key match
  (`password`, `token`, `api_key`, …) in snapshots, changes and metadata; a changed secret
  still shows as a change. The actor comes from `middlewares.GetUser`, the trace and span
  ids from the OpenTelemetry span; event ids are UUIDv7s so the consumer can de-duplicate.
  `Record` is async (bounded queue, retries, drops counted and logged, never fails the
  request); `RecordSync` publishes before returning. `UnaryServerInterceptor` and
  `HTTPMiddleware` record denials and writes on their own, unless the handler recorded
  its own event. `schema/event.v1.json` is the contract for producers in other languages.
- `audit.Derive`: the changes and redaction, with the package's defaults, for an event
  that arrived with only its before/after states (a producer in another language). The
  audit service applies it so every producer's events read alike.
- `telemetry`: OpenTelemetry for every service, as `docs/telemetry.md` has it. `Init` sets
  the tracer and meter providers from the standard `OTEL_*` environment (OTLP/HTTP; with
  no endpoint nothing is exported, but spans still get ids), W3C trace context and
  baggage, and Go runtime metrics. `HTTPHandler` and `Transport` trace HTTP servers and
  clients, `ServerOptions` and `DialOptions` gRPC; each puts a logger carrying
  `trace_id`/`span_id` in the context, so `logger.FromContext` lines link to the trace in
  Grafana.
- `middlewares`: `OnAuthenticated` hooks get the verified caller as soon as
  `AuthUnaryInterceptor`/`AuthStreamInterceptor` accept the token, before
  `RequirePermissions`, so an interceptor running before auth (audit) knows who made a
  call that auth then refuses.

## Changes

- `kafka`: `Produce` puts the context's trace (`traceparent`) in the message headers, and
  the consumer loop runs each handler in a span continuing it.
- New dependencies: `go.opentelemetry.io/otel` v1.39.0 (the version grpc v1.79.1 already
  uses) with its SDK and OTLP/HTTP exporters, and the `otelgrpc`, `otelhttp` and
  `runtime` instrumentation v0.64.0. The `go` line stays at 1.27.4.
